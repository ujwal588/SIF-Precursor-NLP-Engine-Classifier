# SIF Precursor NLP Engine Classifier

An AI/NLP industrial safety analytics project for classifying safety reports as SIF-potential (Serious Injury/Fatality) or non-SIF. It also maps IOGP Life-Saving Rules, extracts recurring precursors, and supports analysis of risk patterns across locations, activities, and barriers through an interactive dashboard.

This repository is the classifier-focused continuation of the SIF Precursor NLP Engine prototype.
